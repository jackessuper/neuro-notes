# NeuroTips

A survival guide for people getting started in neurology, in the spirit of [Gas Notes](https://gasnotes.net).

Content lives in `content/` as Markdown. `python3 build.py serve` previews it locally; pushes to `main` deploy to GitHub Pages. See `CLAUDE.md` for the full layout and authoring reference, and `content/style-guide.md` for formatting examples.
